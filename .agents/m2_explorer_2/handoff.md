## 2. Logic Chain

1. **Step 1 (Input Alignment)**: Pass 2 receives a `ResearchBrief` generated by Pass 1 (`pass1-research.ts`) containing verified facts, obscure metrics, incongruity seeds, and a selected premise angle.
2. **Step 2 (Archetype Dispatch)**: Based on `skill.archetype`, Pass 2 dispatches to either the `generateDeskShowDraft` engine (Archetype A) or the `generatePodcastDraft` engine (Archetype B).
3. **Step 3 (Archetype A Joke Construction)**:
   - Evaluates `calculateClipWordBudgets(durationSeconds, skill, 8)` to calculate per-clip timing and word count boundaries.
   - Prompts Gemini 3.7 Flash with `ThinkingLevel.HIGH` to synthesize verified facts into 3-act beats (`ARCHETYPE_A_STANDARD_ACTS`), generating setup-misdirection jokes, rule-of-three triplets, hyper-specific escalating analogies, rapid punchline tags, callback links, and 8-second Veo visual conditioning prompts.
   - Enforces the **end-of-sentence punchline rule** (the funniest operative word is always placed at the end of the line).
4. **Step 4 (Archetype B Podcast Dynamic Dialogue Tree)**:
   - Reads `skill.podcastDynamics.talkingPointTree` and `driftConfig`.
   - Prompts Gemini 3.7 Flash with `ThinkingLevel.HIGH` to simulate multi-speaker turn-taking across host roles (`lead_host`, `guest_theorist`, `co_host_sounding_board`), classifying each turn as `inquiry`, `speculative_riff`, `diatribe`, `ping_pong`, `backchannel`, `tangent_pivot`, or `snapback`.
   - Embeds authentic acoustic tags (`[laughs]`, `[chuckles]`, `[sighs]`, `[incredulous]`, `[wheezes]`) directly in dialogue lines for Gemini 3.1 Flash TTS.
5. **Step 5 (Resilience & Output Delivery)**: If LLM access is unavailable or mock-tested, a deterministic synthesizer generates compliant beat sequences with valid timing, callbacks, and formulas. The resulting `HeadWriterDraft` is output to Pass 3 (`pass3-voice-prune.ts`).

---

## 3. Caveats

1. **Veo 3.1 Rate Limit vs. Scripting Speed**: While Pass 2 completes in 2–5 seconds with Gemini 3.7 Flash, the downstream video generation in M3 is rate-limited to 2 RPM by Google Veo 3.1. Pass 2's generation of granular 8s visual prompts ensures video generation can execute cleanly in parallel or queued steps.
2. **Deterministic Fallback Scope**: The deterministic fallback synthesizers provide structurally valid 5-beat and 8-turn drafts with proper callback links and word counts, but lack the contextual real-time wit of live Gemini 3.7 Flash inference. They are designed for test suite stability and API outage resilience.

## 4. Conclusion

The implementation architecture for Pass 2 (`app/lib/dramaturgy/pass2-head-writer.ts`) is fully designed with:
- **Clean TypeScript Types & Zod Schemas**: `HeadWriterDraft`, `ComedicBeat`, `PodcastTurn`, `CallbackLink`, `Pass2Input`, `Pass2Result`.
- **Archetype A Engine**: 3-Act rhetorical progression, explicit comedic formulas (`setup_misdirection`, `rule_of_three`, `escalating_analogy`, `rapid_tag`, `callback`), 8-second Veo clip budgets ([17, 23] words/clip), dual-track dialogue + visual prompts.
- **Archetype B Engine**: Dynamic dialogue tree traversal, conversational turn-taking taxonomy, tangent drift calculations, snapback triggers, and acoustic tag embeddings.
- **Prompt Engineering**: High Thinking Level (`ThinkingLevel.HIGH`) system instructions embedding computational humor theory and punchline positioning rules.
- **Resilience Engine**: Deterministic fallback generators guaranteeing 100% test reliability.

All specifications are documented in `.agents/m2_explorer_2/analysis.md`.
